# Intern Hiring Sanity Studio

Sanity Studio for editing the login panel content used by the frontend.

## Run locally

From the frontend repository root:

```bash
npm --prefix sanity-studio install
npm run sanity:dev
```

Or from this studio folder:

```bash
npm install
npm run dev
```

Open `http://localhost:3333`, then create or edit the `Login Hero` document.

The frontend reads the first `loginHero` document from project `41cnp8ig`, dataset `production`.
